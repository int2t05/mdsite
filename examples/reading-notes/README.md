# A Markdown workspace, ready to browse

Keep writing in Markdown. Browse the same files as a clean, searchable website.

## One source, three ways to use it

| Mode | Command | Good for |
| --- | --- | --- |
| Local preview | `mdsite` | Reading and checking notes as you edit |
| Static build | `mdsite build` | Saving a portable copy of the website |
| Online | `mdsite publish --repository owner/notes` | Sharing notes through GitHub Pages |

## Start with one command

~~~powershell
mdsite
~~~

Run it from your Markdown root, or point to a folder with `--path`. The source files stay in place; mdsite reads them through a temporary directory link.
